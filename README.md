# Car-ing is Sharing: Multi-Functional AI Chatbot

## Project Overview

This project was completed as part of a DataCamp project. It focuses on developing an AI-powered chatbot for **Car-ing is Sharing**, an auto dealership company specializing in car sales and rentals.

The goal is to leverage Large Language Models (LLMs) to deliver intelligent customer support and assist human agents with a range of natural language processing tasks.

## Objectives

* Build a chatbot capable of handling multiple NLP tasks.
* Improve customer interaction and support services.
* Assist human agents by automating common text-processing tasks.

## Technologies Used

* Python
* Hugging Face Transformers
* Large Language Models (LLMs)
* Natural Language Processing (NLP)

## Features

The chatbot can perform several tasks, including:

* Sentiment analysis of car reviews.
* Answering customer questions.
* Summarizing text.
* Translating text into different languages.
* Processing textual prompts using pre-trained Hugging Face models.

## Project Structure

* `notebook.ipynb` – Main notebook containing the implementation.
* `README.md` – Project documentation.

## Outcome

This project demonstrates how pre-trained Large Language Models can be integrated into business applications to enhance customer experience and provide intelligent support for automotive sales and rental services.
